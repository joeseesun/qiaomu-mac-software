# 0.3.0 交接

- **0.3.0 新增** `pick` 命令在本机回环地址打开挑选页：真实应用图标、搜索、分组筛选、勾选、改分类、写推荐理由，保存即覆盖写回 selection.json；URL 带随机凭证，保存前不发任何网络请求。应用名改用 Spotlight 显示名，跟随系统语言（腾讯会议、备忘录等），英文系统保持原名。已实机验证完整链路：scan（166 款，中文名正确）→ pick（勾选 3 款写回）→ render → 用 QIAOMU_SOFTWARE_ORIGIN 指向本机网站副本 publish 成功，缺图标才上传。
- **待证实** 挑选页在更多浏览器和超长清单（>100 款）下的体验；kMDItemDisplayName 在个别自签名应用上可能退回文件名。

## 0.2.0 交接

- **已验证优势** 原生扫描、读取主屏幕静态壁纸、提取应用图标和导出 PNG 可以在同一台 Mac 上通过 Node 与系统 osascript 完成。用实机对照了原壁纸、压暗壁纸和纯色三个方案。
- **0.2.0 新增** 渲染时按 SHA-256 导出 128px 图标；发布前先查询网站缺少哪些图标，只上传缺少的；清单带应用 ID 和用户亲口给出的推荐理由。标题已含年份时不再重复年份，海报底部印署名和 software.qiaomu.ai。已在本机网站副本验证：空库上传 14 个图标，重放与已有图标均不再上传，旧版网站照常接收海报。
- **设计优势** 将 qiaomu-info-card-designer 的真实渲染与预览放在上传之前。只发布成图和明确选择的元数据，不依赖图片生成服务。macos-trace 与 dayflow-review 的目录结果提示了活动记录这一相邻问题。本流程选择系统可见日期作为候选信号，不要求持续监视或完整活动轨迹。
- **待证实** 更多 macOS 版本、各助手的 AskUser 组件表现和社区分类效果需要实际用户反馈。终端工具可执行，但没有 Spotlight 六个月活跃天数。自动覆盖系统正在换帧的动态壁纸不在 0.2.0 支持范围。线上图标查询接口需等网站新版部署后生效，在此之前发布会自动跳过图标。
