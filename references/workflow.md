# 工作流与边界

- `inventory.json` 含本机应用路径、候选排名和观测范围。仅保存于本机，勿发布这份文件。应用从 /Applications、~/Applications、/System/Applications 发现；非标准位置可追加 `--root /path/to/apps`。未挂载的卷、不可读目录和没有应用包的命令行程序不在通用扫描范围内。目前单独发现 Claude Code，图标取本机 Claude，缺少时用系统终端。常驻菜单工具和 CLI 的使用频率可能低估。
- `selection.json` 结构为 `{title, year, apps:[{id,name,path,group}]}`。可按用户指示编辑名称、分类、应用顺序及选中项。识别变体或同名应用时按 ID 或路径核对。建议用原始库存条目补入，避免启动其可执行文件。
- `desktop` 用主屏幕的桌面图片并压暗；`night` 压暗更多；`minimal` 用程序生成的渐变。主屏幕桌面图片不可读时，警示用户本次用了渐变并提供指定背景的选项。程序使用可读的壁纸静态图像。屏保和实时视频帧需要用户提供照片文件。
- 同名输出已存在时给修订图取新名字。一张图最多 48 款、7 个分类。对列宽过长的自定义标题应缩短并确认，完整名称仍保留在清单。
- 上传只发给 `https://software.qiaomu.ai`，包括 PNG、分享范围、分享名、海报标题和最终选择的软件名称及分类。上传上限 8 MiB。超限可选择纯色或更换较简单的壁纸后重试。输出与清单哈希不匹配时请重新预览新图。
- 若网络断开，保留原图和同名清单，用同一分享名、标题及范围重试，服务端会复用本次上传编号。成功后本机 `.share.json` 是撤回凭证。公开海报可以进入画廊和搜索；仅链接海报不会出现在画廊。失去凭证可通过作品的举报入口联系维护者。
