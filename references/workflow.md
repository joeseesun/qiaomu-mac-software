# 工作流与边界

- `inventory.json` 含本机应用路径、候选排名和观测范围。仅保存于本机，勿发布这份文件。应用从 /Applications、~/Applications、/System/Applications 发现；非标准位置可追加 `--root /path/to/apps`。未挂载的卷、不可读目录和没有应用包的命令行程序不在通用扫描范围内。目前单独发现 Claude Code，图标取本机 Claude，缺少时用系统终端。常驻菜单工具和 CLI 的使用频率可能低估。
- `selection.json` 结构为 `{title, year, author?, apps:[{id,name,path,group,note?}]}`。可按用户指示编辑名称、分类、应用顺序、选中项、推荐理由（`note`，≤60 字）和署名（`author`，≤40 字）。识别变体或同名应用时按 ID 或路径核对。建议用原始库存条目补入，避免启动其可执行文件。标题已含年份（如“2026 AI 开发工作台”）时不再重复绘制年份；`"year": null` 表示不画年份。
- `desktop` 用主屏幕的桌面图片并压暗；`night` 压暗更多；`minimal` 用程序生成的渐变。主屏幕桌面图片不可读时，警示用户本次用了渐变并提供指定背景的选项。程序使用可读的壁纸静态图像。屏保和实时视频帧需要用户提供照片文件。海报底部印署名和 software.qiaomu.ai。
- `render` 同时把选中软件的 128px 图标导出到 `成图.png.icons/<sha256>.png`，并在清单里记录每款软件的图标指纹。图标导出失败不影响海报，只是网站上用占位图标。
- 同名输出已存在时给修订图取新名字。一张图最多 48 款、7 个分类。对列宽过长的自定义标题应缩短并确认，完整名称仍保留在清单。
- 上传只发给 `https://software.qiaomu.ai`，包括 PNG、分享范围、分享名、海报标题，以及最终选择的软件名称、分类、推荐理由和应用 ID。发布前脚本先把图标指纹发给 `/api/v1/icons/lookup`，只上传网站还没有的图标；网站校验指纹并重新编码。同一款软件有多个版本的图标时，网站显示被最多公开海报使用的那个。查询失败时不传图标，海报照常发布。海报上限 8 MiB。超限可选择纯色或更换较简单的壁纸后重试。输出与清单哈希不匹配时请重新预览新图。
- 若网络断开，保留原图、同名清单和图标目录，用同一分享名、标题及范围重试，服务端会复用本次上传编号。成功后本机 `.share.json` 是撤回凭证。公开海报可以进入画廊、软件榜和搜索；仅链接海报不会出现在画廊，也不计入软件榜。失去凭证可通过作品的举报入口联系维护者。
- 维护者可设 `QIAOMU_SOFTWARE_ORIGIN=http://127.0.0.1:端口` 对本机网站副本测试发布；该变量只接受 https 或本机 http。
